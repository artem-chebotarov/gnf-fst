---

This library provides a lightweight and efficient way to implement remote-control navigation in your Tizen TV applications. By simply following a specific HTML markup structure, you can enable seamless focus management. 

Additionally, the library ensures accessibility by automatically adapting the focus flow for screen readers, making your application inclusive for visually impaired users.

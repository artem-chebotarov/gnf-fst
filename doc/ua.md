# Gnf-fst — навігація для телевізорів

**Gianna Navigation Focus for Samsung Tizen TV (gnf-fst)** — це невеликий JavaScript-клас розміром менше 3 КБ, який допомагає реалізувати навігацію в телевізійних застосунках за допомогою пульта.

Бібліотека не має залежностей і відповідає лише за навігацію між елементами інтерфейсу. Вона не займається стилями, рамками, шрифтами чи анімаціями.

Проєкт створювався з урахуванням доступності для незрячих користувачів. Вам не потрібно вручну додавати `aria-*` атрибути — бібліотека робить це автоматично.

> ⚠️ Увага: бібліотека створювалася спеціально для Samsung Tizen TV.  
> Можлива робота на LG TV. Android TV підтримується лише у PWA-застосунках.

---

# Структура розмітки

Для правильної навігації важливо дотримуватись структури інтерфейсу.

Структура складається з:

- контейнера
- рядків
- стовпців

Навіть якщо вам потрібен звичайний вертикальний список, кожен рядок повинен містити хоча б один стовпець.

## Приклад HTML

```html
<div id="container">

    <div>
        <div>Перший стовпець</div>
        <div>Другий стовпець</div>
    </div>

    <div>
        <div>Перший стовпець</div>
        <div>Другий стовпець</div>
    </div>

</div>
```

Можна використовувати будь-які HTML-елементи, а не лише `div`.

# Методи

## init()

Ініціалізує контейнер і додає необхідні атрибути для навігації.

### Приклад

```js
const gnf = new Gnffst();

gnf.init("#container");
```

Можна ініціалізувати одразу кілька контейнерів.

```js
gnf.init("#container, #menu, #settings");
```

---

## switch()

Робить контейнер активним для навігації.

Рекомендується викликати одразу після `init()`.

### Приклад

```js
gnf.switch("#container");
```

---

## go()

Переміщує фокус усередині контейнера.

Підтримувані напрямки:

- `up`
- `down`
- `left`
- `right`

### Приклад

```js
gnf.go("down");
gnf.go("up");
gnf.go("left");
gnf.go("right");
```

Метод найкраще використовувати в обробниках `keydown` або `keyup`.

---

## addCallbacks()

Додає callback-функції для меж контейнера.

Вони викликаються, коли користувач намагається вийти за межі інтерфейсу.

### Приклад

```js
gnf.addCallbacks("#container", {
    left: () => console.log("left edge"),
    right: () => console.log("right edge"),
    up: () => console.log("top edge"),
    down: () => console.log("bottom edge"),
});
```

Callback отримує поточний екземпляр класу.

### Приклад

```js
gnf.addCallbacks("#container", {
    up: (t) => console.log(t.focus.id)
});
```

# Як це працює

Бібліотека написана на чистому JavaScript і не потребує сторонніх залежностей.

Її головне завдання — забезпечити просту та зрозумілу навігацію в TV-інтерфейсах.

Якщо контейнер видаляється з DOM, пов’язані callback-функції також автоматично видаляються завдяки `WeakMap`.

---

# Доступність

Бібліотека автоматично додає:

- `tabindex`
- `aria-label`
- `aria-posinset`
- `aria-setsize`

Це покращує підтримку скрінрідерів.

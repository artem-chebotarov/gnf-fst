# Gnf-fst — навигация для телевизоров

**Gianna Navigation Focus for Samsung Tizen TV (gnf-fst)** — это небольшой JavaScript-класс размером менее 3 КБ, который помогает организовать навигацию по интерфейсу телевизионных приложений с помощью пульта управления.

Библиотека не имеет зависимостей и отвечает только за навигацию между элементами интерфейса. Она не занимается стилями, рамками, шрифтами или анимациями.

Проект разрабатывался с учётом доступности для незрячих пользователей. Вам не нужно вручную добавлять `aria-*` атрибуты — библиотека делает это автоматически.

> ⚠️ Внимание: библиотека создавалась специально для Samsung Tizen TV.  
> Возможна работа на LG TV. На Android TV поддерживаются только PWA-приложения.

---

# Структура разметки

Для корректной навигации важно соблюдать структуру интерфейса:

- контейнер
- строки
- столбцы

Даже если вам нужен обычный вертикальный список, каждая строка всё равно должна содержать хотя бы один столбец.

## Пример HTML-разметки

```html
<!-- Контейнер -->
<div id="container">

    <!-- Первая строка -->
    <div>
        <div>Первый столбец</div>
        <div>Второй столбец</div>
    </div>

    <!-- Вторая строка -->
    <div>
        <div>Первый столбец</div>
        <div>Второй столбец</div>
    </div>

</div>
```

Можно использовать любые HTML-элементы, а не только `div`. Главное — соблюдать структуру: контейнер → строки → столбцы.

# Методы

## init()

Инициализирует контейнер и добавляет необходимые атрибуты для навигации.

### Пример

```js
const gnf = new Gnffst();

gnf.init("#container");
```

Можно инициализировать сразу несколько контейнеров.

### Пример

```js
gnf.init("#container, #menu, #settings");
```

---

## switch()

Делает контейнер активным для навигации.

Рекомендуется вызывать сразу после `init()`.

### Пример

```js
gnf.switch("#container");
```

---

## go()

Перемещает фокус внутри контейнера.

Поддерживаемые направления:

- `up`
- `down`
- `left`
- `right`

### Пример

```js
gnf.go("down");
gnf.go("up");
gnf.go("left");
gnf.go("right");
```

Лучше всего использовать метод внутри обработчиков `keydown` или `keyup`.

---

## addCallbacks()

Позволяет назначить обработчики выхода за границы контейнера.

Если пользователь попытается выйти за пределы интерфейса, будет вызван соответствующий callback.

### Пример

```js
gnf.addCallbacks("#container", {
    left: () => console.log("left edge"),
    right: () => console.log("right edge"),
    up: () => console.log("top edge"),
    down: () => console.log("bottom edge"),
});
```

Callback получает текущий экземпляр класса.

### Пример

```js
gnf.addCallbacks("#container", {
    up: (t) => console.log(t.focus.id)
});
```

# Как это работает

Библиотека написана на чистом JavaScript и не требует сторонних зависимостей.

Основная задача класса — обеспечить удобную навигацию по интерфейсу телевизионного приложения.

Если контейнер удаляется из DOM, связанные callback-функции также автоматически удаляются благодаря использованию `WeakMap`.

---

# Доступность

Библиотека автоматически добавляет:

- `tabindex`
- `aria-label`
- `aria-posinset`
- `aria-setsize`

Это помогает сделать интерфейс более удобным для пользователей со скринридерами.
